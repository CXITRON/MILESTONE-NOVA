# Request U0002

- **Request ID:** U0002
- **Priority:** L
- **Date:** 2026-10-09
- **Status:** In Progress

## Title

하단 RGB LED 비정상 출력 수정 및 기존 프레임 안정성 보존

## Summary

MILESTONE NOVA 기기의 MEDIA 재생, AP SYNC, NOW 등의 환경에서 하단 RGB LED가 간헐적으로 비정상적인 색상을 출력하거나 의도하지 않게 깜빡이는 현상이 발생함.

관련 LED 제어 로직과 상태 전환 과정을 분석하여 근본 원인을 파악하고 수정할 것.

단, 이전 작업에서 해결한 MEDIA 및 AP SYNC의 프레임 관련 문제가 재발하지 않는 것을 본 요청의 최우선 조건으로 지정함.

## Requirements

### 1. 최우선 조건: 기존 프레임 안정성 보존

- **[P0 / 최우선] 기존에 해결한 MEDIA 및 AP SYNC 프레임 관련 오류가 재발하지 않도록 할 것.**
- 기존 프레임 생성, 전송, 수신, 동기화, 갱신 및 표시 로직의 정상 동작을 유지할 것.
- 기존 프레임 관련 수정 사항을 임의로 되돌리거나 우회하지 말 것.
- LED 수정과 프레임 처리 안정성이 충돌할 경우 프레임 처리 안정성을 우선할 것.
- 프레임 관련 코드 변경은 불가피한 경우에만 수행하고, 변경 근거와 영향 범위를 보고할 것.

### 2. LED 출력 문제 해결

- MEDIA, AP SYNC, NOW 환경에서 발생하는 비정상적인 LED 점멸 및 색상 출력 문제를 해결할 것.
- 기존 음악 반응형 LED 효과와 정상적인 애니메이션을 유지할 것.
- 모드 전환 과정에서 이전 LED 상태나 출력 데이터가 비정상적으로 잔류하지 않도록 할 것.
- LED 제어 루틴 간 충돌, 중복 갱신 및 타이밍 문제를 점검할 것.
- 기존 기능 및 성능에 회귀 문제가 발생하지 않도록 할 것.

## Details

### 1. 원인 분석

다음 항목을 중심으로 조사할 것.

1. LED 제어 코드의 전체 호출 경로 및 상태 관리 구조.
2. MEDIA, AP SYNC, NOW에서 LED 출력 갱신이 중복 실행되는지 여부.
3. 모드 진입 및 종료 시 LED 상태 초기화와 제어권 전환.
4. 비동기 작업, 타이머, 태스크 및 콜백 사이의 데이터 경쟁 가능성.
5. LED 버퍼, 색상 변환, 출력 타이밍 및 드라이버 설정.
6. 음악 반응형 LED 애니메이션과 다른 출력 루틴 사이의 간섭.
7. 프레임 처리와 LED 출력 처리 사이의 자원 및 실행 타이밍 충돌 가능성.

추측만으로 원인을 확정하지 말고 실제 코드와 재현 가능한 근거를 바탕으로 판단할 것.

### 2. 수정 원칙

- 문제의 근본 원인을 해결할 것.
- 기존 정상 동작을 최대한 보존할 것.
- 불필요한 대규모 리팩터링을 수행하지 말 것.
- 기존 프레임 처리 구조를 변경하지 않는 해결책을 우선 검토할 것.
- LED 효과를 제거하거나 단순화하는 방식으로 문제를 회피하지 말 것.
- 수정 범위를 최소화하고 관련 변경 사항을 명확히 기록할 것.

### 3. 회귀 방지

기존 MEDIA 및 AP SYNC 프레임 관련 수정 사항을 우선 확인하고, LED 수정 전후의 동작을 비교할 것.

특히 다음 사항을 점검할 것.

- 프레임 갱신 정상 여부.
- 프레임 표시 정상 여부.
- 프레임 전송 및 수신 정상 여부.
- AP SYNC 동기화 정상 여부.
- MEDIA 재생 중 프레임 처리 정상 여부.
- 모드 전환 후 프레임 처리 정상 여부.
- 장시간 실행 및 반복 전환 시 안정성.

기존 프레임 문제를 재발시키는 수정 사항은 허용하지 않음.

## Completion Criteria

### 최우선 필수 조건

- **MEDIA 및 AP SYNC의 기존 프레임 관련 문제가 재발하지 않을 것.**
- 기존 프레임 처리 기능이 정상적으로 유지될 것.
- 관련 회귀 테스트 결과를 보고할 것.
- 실제 기기에서 검증하지 못한 항목은 검증 완료로 표시하지 말 것.

### LED 수정 완료 조건

- MEDIA, AP SYNC, NOW에서 비정상적인 LED 점멸 및 색상 출력 문제가 해결될 것.
- 기존 음악 반응형 LED 효과가 정상 작동할 것.
- 모드 전환 및 반복 실행 시 LED 상태가 정상적으로 관리될 것.
- LED 제어 루틴 간 충돌이 해결될 것.
- 펌웨어 빌드가 정상적으로 완료될 것.
- 수정 파일, 원인, 해결 방법 및 테스트 결과를 보고서에 기록할 것.
