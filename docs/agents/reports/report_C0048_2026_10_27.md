## Title

Focus 화면에서 집중 시간을 바로 고치는 편집 모드(5분·1분·1초 단위)

## Summary

집중 시간은 그동안 설정 AP(포털)나 기기 설정 > Focus minutes(1분 단위)에서만 바꿀 수 있었다. 사용자가 Focus 화면에서 바로 바꾸는 편집 모드를 골랐고, 편집 중 단위를 5분, 1분, 1초로 바꿀 수 있게 해 달라고 했다. 대기 중인 Focus 화면에서 OK를 길게 누르면 편집 모드가 열리고, PREV/NEXT로 증감, MENU로 단위 전환, OK나 BACK으로 끝낸다. 바꾼 값은 기존 `focus_seconds` 설정으로 저장된다.

## Related Requests

활성 Request 없음(`scripts/request/queue.sh`: No active requests). 사용자 직접 지시로 진행했다.

## Work Performed

- 입력(`src/app/App.cpp`):
  - Focus 화면에서 길게 OK는 타이머가 대기(Idle)일 때만 편집 모드를 연다. 시작·일시정지·완료 상태에서는 예전처럼 기본 시간으로 reset한다. 대기 상태의 reset은 원래 아무 변화가 없던 동작이라 기존 기능을 잃지 않는다.
  - 편집 중 PREV/NEXT는 현재 단위만큼 증감한다. PREV/NEXT는 원래 누르고 있으면 180 ms마다 repeat되므로 길게 누르면 빠르게 바뀐다. 짧게 누를 때 화면 이동은 편집 중에만 막힌다.
  - 편집 중 MENU 짧게는 메뉴를 여는 대신 단위를 5분 → 1분 → 1초 순서로 바꾼다. 편집을 열 때마다 5분부터 시작한다. 버튼 다섯 개(MENU, BACK, PREV, OK, NEXT) 중 사용자가 말한 "mode 버튼"은 모드 메뉴를 여는 MENU로 해석했다. MENU 길게(OFF 요청)는 바꾸지 않았다.
  - OK 짧게나 BACK 짧게로 편집을 끝낸다. 다른 화면으로 바뀌면 편집 상태는 자동으로 풀린다.
  - 값 변경은 기기 설정의 Focus minutes와 같은 함수(`adjustFocus`)를 쓴다. 범위는 기존 설정 범위 60-14400초(1분-240분), 대기 중인 타이머도 바로 새 시간으로 맞추고 설정 저장을 예약한다. 기기 설정 화면은 1분 단위를 그대로 쓴다.
- 화면(`src/ui/CoreScreens.cpp`, `src/ui/Ui.cpp`, `src/ui/Ui.h`):
  - 편집 중에는 시간이 주황색(설정 편집과 같은 `color::warning`)이고, 아래 줄에 `Step 5 min` / `Step 1 min` / `Step 1 sec`을 보인다.
  - 아래 안내 줄: 대기 `OK Start  Hold Minutes`, 편집 `<> MENU Step  OK Done`, 시작 뒤 기존 `OK Start/Pause  Hold Reset`.
  - 새 문구는 모두 영어라 시론어 모드에서도 그대로 보인다(영어는 바꾸지 않는다는 사용자 결정). 새 한국어 문구를 만들지 않아 시론어 번역 표(`ui-strings.tsv`)에 추가할 단어가 없다.
  - 단위 표는 `Ui.h`의 `focusSteps`/`focusStepSeconds` 하나에 두어 입력과 화면이 같은 값을 쓴다.
