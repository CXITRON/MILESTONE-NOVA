## Title

현재 펌웨어의 화면·상태 60개 렌더링과 분류별 미리보기 제공

## Summary

기기의 현재 C++ UI와 U8g2 폰트를 호스트에서 실행해 240×320 화면 60개를 생성했다.
기존 36개 장면에 메뉴 하단, 설정 편집, OFF, NOW 대기·누락 상태, Sync 연결,
환경 경고, 타이머 상태, 업데이트 진행·실패 등을 추가했다. 실제 제품 UI 소스와
디자인은 변경하지 않았다.

분류와 화면 이름을 붙인 Markdown/HTML 갤러리, 개별 PNG, 9개씩 묶은 비교 PNG
7장을 제공한다. 날짜·곡·센서·진단 값과 아트는 예시 데이터다.

## Work Performed

1. 기존 렌더링 도구와 실제 UI 분기·화면 enum을 확인했다.
2. 장면마다 View/Settings를 초기화해 이전 장면의 설정이 다음 장면으로 넘어가지
   않게 했다. 메뉴 상·하단, NOW 5개 레이아웃과 제어 가능/불가, 진단 12페이지를 포함했다.
3. 추가 상태를 실제 UI 렌더러에 입력하고 파일명·분류·제목 manifest를 생성했다.
   집중 타이머는 최소 60초 제한을 반영해 완료 상태를 만들고 해당 상태를 assert했다.
4. manifest에 있는 PPM만 읽어 원본 크기 PNG와 비교 이미지를 생성한다. 이전 실행의
   다른 PPM이 남아 있어도 새 갤러리에 임의로 포함하지 않는다.
5. 60개 이미지를 CORE, NOW, MEDIA/SYNC, 메뉴/설정, 업데이트/전원, 진단으로 분류했다.
   HTML은 외부 자산·서버·JavaScript 없이 로컬 파일로 열 수 있다.

## Issues / Limitations

- 정지 이미지다. marquee의 한 시점만 표시하며 영상·전환·실제 버튼 동작은 재현하지 않는다.
