## Title / Summary

NOVA 0.1.20 SD 부팅 스캔 워치독 대응 릴리스

SD 장착 시 0.1.18에서 약 6초마다 reset=6 재부팅이 반복된 사용자 보고에 대응해, SD 순회 모든 경로가 idle 태스크 실행 기회를 주도록 수정했다. 캐시가 많은 카드의 CPU 양보 공백과 사용자 증상은 부합하지만 해당 기기의 최종 원인과 해결 여부는 실기 미검증이다. 상세 조사·수정 근거는 C0042에 있다. 기존 0.1.19 안정성 수정도 포함한다.

## Issues / Limitations / Remaining Work

- 기기 SD 장착 부팅과 watchdog 안정성, 큰 카드의 scan elapsed_ms는 미검증이다. 큰 폴더의 FAT 탐색 비용과 SD 단일 호출의 장기 blocking까지 이번 변경으로 없어지는 것은 아니다.
- 기존 OTA는 SD 저장을 사용한다. SD 없는 OTA는 불가능하며, 현재 카드로 부팅이 반복되면 USB 적용 또는 원본 데이터 보존 후 카드 복구가 필요하다. 사용자는 여분 SD가 없다고 했고 원본 카드 파일 접근 가능 여부는 아직 답을 받지 않았다.
- RTC는 사용자 의도대로 제거된 상태라 미검출을 장애로 취급하지 않는다.
- 영상 frame decode/LCD 전송, 파티션, NVS 설정, 워치독 제한은 변경하지 않았다.
- C0032의 과거 0.1.17 rollback까지 해결됐다고 간주하지 않는다.
