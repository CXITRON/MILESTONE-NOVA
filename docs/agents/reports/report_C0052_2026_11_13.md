## Title

수능 시간표 연습 모드 추가(원하는 때 1교시부터 시작)

## Summary

사용자 요청 원문: "지금 노바에 수능시간표 모드 있잖아 그거 정해진 시간 말고 원하는 시간에 1교시부터 시작하는 기능도 원해"

사용자 선택(질문 답): 시작 시점은 "08:25 예비령", 시작 방식은 "버튼 누른 순간".

수능 시간표 화면에서 OK를 길게 누르면 연습이 시작된다. 누른 순간을 08:25 1교시 예비령으로 보고, 그 뒤로는 실제 속도로 시간표가 흐른다. 15분 뒤 본령, 2시간 15분 뒤 2교시 수학 본령 중 같은 식이다. 다시 OK를 길게 누르면 실제 시간표로 돌아간다. 시작 시각은 NVS 별도 키 `exam-run`에 저장하므로 재부팅해도 연습이 이어지고, 기존 설정 레코드는 바뀌지 않는다.

## Work Performed

- `src/core/Logic.h/.cpp`: `examPracticeOrigin`(08:25)과 `examPracticeSeconds(now, start)`를 추가했다. 시작 이후 경과 시간을 08:25에 더해 시간표 초로 바꾸고, 범위는 0..86399로 제한한다. 그래서 하루 넘게 켜 두면 "시험 종료"에 머물고, 시계가 뒤로 가면 앞 단계로 돌아간다.
- `src/settings/Store.h/.cpp`: `examPracticeStart()`와 `saveExamPracticeStart()`를 추가했다. NVS 키는 `exam-run`(uint32 UTC epoch, 0이면 꺼짐)이고, 쓴 뒤 다시 읽어 확인한다. `reset()`이 메모리 값도 기본값으로 돌리도록 했다. 이때 기존에 빠져 있던 `examSecondLanguage_` 초기화(NVS는 지워지지만 메모리 값은 남던 문제)도 함께 고쳤다.
- `src/app/App.cpp`: 수능 시간표 화면에서 OK 길게 누름으로 연습을 시작하거나 끝낸다. 시계가 맞지 않으면 "시간 설정 필요"를, 저장에 실패하면 "설정 저장 실패"를 띄운다. 짧게 누르면 기존처럼 제2외국어 응시 여부가 바뀐다.
- `src/ui/Ui.h`, `src/ui/CoreScreens.cpp`: View에 `examPracticeStart`를 추가했다. 연습 중에는 제목 옆에 "연습"을 표시하고, 다음 타종 시각을 기기 시계 기준으로 보여 준다(예: 19:00 시작이면 "준비령 19:10"). 오른쪽 위 시계는 실제 시각 그대로다.
- `src/ui/Ui.cpp`: 하단 안내가 화면 폭에 맞도록 "OK 제2외국어 O/X  Hold 연습"(연습 중에는 "Hold 연습끝")으로 바뀌었다.
- `tests/test_core.cpp`: 시작 순간 예비령, 15분 뒤 국어 본령, 2시간 15분 뒤 수학, 시계 역행, 사흘 뒤 종료를 검사한다.
- `tests/update/test_firmware.cpp`, `tests/update/support/Preferences.h`: 테스트용 NVS에 `getUInt/putUInt`를 추가했다. `exam-l2`와 `exam-run`의 저장, 재로드, 쓰기 실패, reset 초기화, 설정 레코드 a/b가 바이트 단위로 그대로인지 검사한다.
- `tests/render/render_ui.cpp`: 19:00 연습 시작 화면과 21:15(=10:40 수학) 화면을 추가했다.
- `README.md`: 버튼 표와 수능 시간표 절에 연습 모드를 적었다.
