## Title

NOVA 1.0.0 복구 기능 정식 최신 릴리스

## Summary / Request Resolution

사용자의 릴리스 승인으로 C0044/C0045의 복구 기능을 1.0.0으로 정식 게시했다. GitHub latest manifest와 서명 이미지를 다시 내려받아 버전·target·크기·SHA-256·RSA 서명을 검증했다. 기기에 설치하지 않았다.

## Work Performed / Changes

- 원격 main이 기존 HEAD dabd399이고 v1.0.0이 없음을 확인했다.
- 현재 source와 staging .h/.cpp(생성 Assets.cpp 제외), 현재 portal 자산으로 다시 생성한 Assets.cpp, 미서명 이미지 버전과 SHA-256이 최종 C0044 검증 당시와 같음을 확인했다. 새 소스 변경이 없어 빌드·시험을 반복하지 않았다.
- 복구 코드·시험·README·C0044/C0045만 24개 파일로 stage하고 staged diff 범위와 diff check를 확인했다. 기존 board.py/협업 게시판/과거 보고서/U0002 이동/미추적 .claude 등은 포함하거나 되돌리지 않았다.
- 기존 RSA 개인키의 공개키가 Trust.h와 동일함을 확인했다. release.py로 SDK 서명과 서명 검증을 마쳤다. 개인키 내용은 출력하거나 전송하지 않았다.
- 소스 commit `bb16c21`(feat(recovery): add safe boot and SD-free signed firmware updates)에 v1.0.0 annotated tag를 만들고 main+tag를 atomic push했다. 작성자 identity는 저장소 기존 설정을 사용했고 agent trailer를 넣지 않았다.
- `nova-1.0.0.bin`, `stable.json`을 정식 최신 GitHub release로 게시했다. 릴리스 설명에 사용법과 비활성 rollback 슬롯 삭제 가능성, RTC RAM 보존 한계, 새 기능 실기 미검증을 명시했다.
