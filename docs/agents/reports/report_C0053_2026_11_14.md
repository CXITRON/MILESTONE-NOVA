## Title

수능 시간표 연습 모드에 준비령 건너뛰기(NEXT 길게), 단계 이동(PREV/NEXT), 단계별 하단 LED 추가

## Summary

사용자 요청 원문은 세 개다.
- "nova 준비령 스킵하는 기능도 추가해줘"
- "다음 이전 버튼 등을 통해서 다음 시간표로 넘어가는 기능 등도 있었으면 좋겠어"
- 릴리스 진행 중(서명·커밋 전): "아 단계 별로 하단led도 활용하고 싶어"

연습 중 대기 단계에서 NEXT를 길게 누르면 예비령과 준비령을 건너뛰고 바로 다음 시험 시작으로 넘어간다. 예를 들어 연습을 시작한 직후(08:25 예비령) 누르면 08:40 국어 본령부터 흐른다. 쉬는 시간과 점심도 대기 단계라서 같은 방법으로 넘길 수 있다.

연습 중에는 NEXT 짧게 누름이 다음 타종 단계로, PREV 짧게 누름이 지금 단계의 시작(시작한 지 5초 안이면 앞 단계)으로 이동한다. 연습 중이 아닐 때는 기존처럼 화면 이동이다.

이동은 저장된 연습 시작 시각(NVS `exam-run`)을 이동한 만큼 옮기는 방식이다. 새 NVS 키나 상태가 없고 재부팅해도 이동한 위치에서 이어진다.

수능 시간표 화면에서는 하단 LED 5개가 단계를 보여 준다. 실제 시간표와 연습 모두 해당한다.
- 예비령: 호박색 고정
- 준비령, 영어 듣기 음질 테스트: 호박색 호흡
- 시험 중: 남은 시간만큼 파란 LED가 켜지고 줄어든다
- 종료 10분 전: 전체 주홍색 호흡
- 쉬는 시간, 점심, 회수 시간: 은은한 녹색
- 시험 종료: 녹색 웨이브
- 단계가 바뀌는 순간(타종, 연습 중 이동): 흰색 1.5초

사용자가 색과 효과를 따로 정하지 않아 내가 골랐다.
