## Title

실물 배선도·LOLIN S3 Pro 회로도 대조와 전원·외장 부품 배선 문서화

## Summary

사용자가 제공한 앞면·뒷면 배선도(RED/GREEN status LED 제외)를 다음 자료와 대조했다.

- `src/board/Board.h`
- LOLIN S3 Pro 공식 회로도 V1.0.0

대조 결과 LCD, 버튼, I2C, RGB 데이터 경로가 모두 코드와 일치해 펌웨어 수정은 필요하지 않았다.

기존 문서에는 5V_AUX의 출처와 배터리 divider의 위치가 빠져 있었다. 다음 내용을
README와 실물 점검표에 기록했다.

- 5V_AUX: DM13B buck-boost 모듈에서 만든다.
- 배터리 divider: 보드에 내장되어 있으며 JP2 `BAT_AD`를 거쳐 연결된다.
- 74HCT125N 채널 구성과 SK6812 3535 사양.
- OFF 중 전류 소모.

## Work Performed

1. LOLIN S3 Pro 회로도 V1.0.0을 확인했다.
   - 배터리 측정: VBAT─R7 100 kΩ─AD_BAT─R8 100 kΩ─GND, C4 100 nF.
     AD_BAT는 JP2 `BAT_AD`를 거쳐 IO3에 연결된다. 기존 코드의 ×2 환산
     (`src/sensors/Sensors.cpp`)과 일치한다.
   - 보드 내장 핀: SD(11/12/13, CS 46), WS2812B(IO38), I2C 커넥터(9/10)가 `Board.h`와 일치한다.
   - 보드 TFT 커넥터 J2(48/47/21/14/45): 사용자가 쓰지 않는다. `Board.h`에서도 RESERVED로 비워 두었다.
   - `VIN`: USB 연결 시 VBUS(1N5819 경유), 배터리만 있을 때 VBAT(CJ2301 경유)가 나온다.
2. 사용자 배선도의 각 선을 GPIO와 대조했다.
   - LCD: BL 18, D/C 17, RST 16, CS 15, SCK 7, DIN 6, VCC 3V3.
   - 버튼: BACK 39, PREV 40, OK 5, NEXT 41, MENU 42.
   - DS3231·AHT10: SDA 9, SCL 10, 3V3.
   - RGB: GPIO2 → 74HCT125N 4A/4Y → 510 Ω → LED1.
     4OE = GND, 미사용 1A–3A = GND, 1OE–3OE = VCC, VCC = DM13B 출력.
3. RGB 코드 설정을 SK6812 3535 RGB(SZH-LD159)와 대조했다.
   - `NEO_GRB + NEO_KHZ800`이 3색 SK6812에 맞다.
   - 밝기 상한 96/255에서 5개 합계 약 70 mA로 추정했다.
4. README 하드웨어 절의 GPIO 2·3 설명을 갱신했다. `전원 및 외장 부품 배선` 절에는
   부품별 연결, 조립 순서, OFF 중 5V_AUX 미차단 영향을 추가했다.
5. 실물 점검표에 다음을 추가·구체화했다.
   - 5V_AUX 사전 측정 항목 추가.
   - 배터리 행: JP2 확인.
   - RGB 행: GRB, 상한, 채널 고정.
   - 전류 행: OFF 대기 전류.

## Issues / Limitations

- JP2 상태는 회로도 기호(open으로 보임)만 보고 판단했다. 실물 보드 출고 상태는 확인하지 않았다.
- 사용자 배선도 이미지 해상도 한계로 LED 간 DOUT→DIN 데이터 체인과 버튼 공통 GND의 끝점은
  끝까지 추적하지 못했다. 실물에서 통전 확인이 필요하다.
- DM13B의 대기 전류, 최대 출력, EN 핀 유무는 데이터시트를 확인하지 않았다.
- OFF 중 5V_AUX가 차단되지 않는다. 대기 시간 영향은 실측해야 한다.
