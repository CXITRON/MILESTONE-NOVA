## Title

5개 상태 LED 효과 확장 및 앨범아트 실패 알림 제한

## Summary

NVS/Wi-Fi 우선 처리로 남아 있던 LED 개선을 사용자의 직접 지시로 구현했다.
기존 하나의 웨이브와 색상 분기에서 부팅·NOW 연결·음악·로컬 MEDIA·AP·Sync·타이머·
업데이트·배터리/온도 상태별 효과로 확장했다. 앨범아트 실패는 곡당 한 번 짧게 알리고
기본 효과로 돌아가며, 같은 곡의 자동 재시도/SD 갱신마다 반복하지 않는다.

## Related Requests

U0001의 RGB/장시간 운용 기능과 관련된다. 전체 U0001 완료를 의미하지 않는다.
직접 명령: 상황별 효과 확장 및 앨범아트 불러오기 실패 예외 처리.

## Work Performed

- `LightEffects`가 입력 상태로부터 5개 RGB 값을 계산하고, `Rgb`는 실제 LED 순서/전송만 담당한다.
- 효과 우선순위: 소등 → 임계 경고 → 업데이트 → 일반 경고 → 부팅 → Sync 끊김 →
  AP 대기 → 타이머 완료 → 아트 알림 → 재생/타이머/대기.
- 음악/로컬 MEDIA/Sync는 서로 다른 색의 웨이브. 일시정지는 양끝 고정광.
  NOW 연결 대기는 가운데 파란 호흡, AP 대기는 이동점, Sync 끊김은 양끝 주황 호흡.
- 타이머 실행/일시정지/완료, 업데이트 진행, 저전압/온도 주의·임계, 일반 대기를 구분한다.
- 앱은 실제 playback의 로컬/Sync 재생 상태를 전달한다. BLE 음악 상태로 대체하지 않는다.
- 밝기 제한·야간 제한·LED 끄기 설정과 우측부터 연결된 실제 LED 순서를 보존한다.
  40 ms 주기의 기존 갱신 구조를 유지하며 효과 계산에 동적 할당/대기 루프를 추가하지 않는다.

### 앨범아트 예외 처리

- 연결된 NOW에서 처음 온라인 조회를 기다릴 때만 최대 8초 로딩 효과를 낸다.
- 성공은 녹색 0.7초, 실패는 가운데 주황색 1.2초. 각각 곡당 최대 한 번이다.
- 곡 식별에는 세션 generation을 사용한다. SD 자산 revision은 새 곡으로 취급하지 않는다.
- 정상 커버가 남아 있으면 실패 표시를 하지 않는다. 오프라인/자동 조회 끄기/차단/단순 파일 없음은
  그 자체로 실패 신호를 만들지 않는다. 실제 온라인 실패 또는 캐시 없는 SD 읽기 오류를 구분한다.
- 실패 뒤 재시도하는 동안 로딩/실패 효과를 반복하지 않는다. 이후 성공하면 성공 알림은 가능하다.
- 상위 효과에 가려진 알림도 시간이 지나면 만료된다. AP를 닫은 뒤 오래된 오류를 재생하지 않는다.
- 기존 Artwork 수신 generation 검사를 유지하여 오래된 결과는 현재 곡의 LED 실패 상태를 바꾸지 않는다.
