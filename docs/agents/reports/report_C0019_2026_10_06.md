## Title

AP 동기 재생 시작 지연·늦은 화면 전환 경로 수정

## Summary

사용자는 Google 앱에서 오디오 재생과 동기 연결을 모두 시도했으나 기기가 AP 화면에 남고,
휴대폰을 집 Wi-Fi로 바꾸면 정지 영상이 뒤늦게 표시된다고 보고했다.
코드에서 동기 시작 HTTP 요청이 SD 영상 전체 검증을 기다리고, 브라우저 연결이 사라져도
검증 뒤 재생 화면 전환을 요청하는 경로를 확인했다. 검증을 비동기 진행률 조회로 변경했다.
실제 증상과 이 경로의 인과관계는 실기 재현으로 추가 확인해야 한다.

## Related Requests

직접 버그 수정 지시를 우선 처리했다. U0001은 계속 In Progress로 유지한다.

## Work Performed

- SD 전체 프레임·크기·CRC 검증을 유지하면서 별도 작업에서 수행하고 같은 identity로 상태를 조회한다.
- 검증 완료 후 실제 후속 HTTP 요청이 도착해야 SyncStart를 dispatch한다. 검증 작업 자체는 화면을 바꾸지 않는다.
- 검증 중 충돌하는 SD API/로그 쓰기를 억제한다. 취소 및 검증된 파일을 변경하는 요청을 처리한다.
- 브라우저의 검증 진행률·취소·활성화 응답과 취소의 경합을 처리하고 검증 중 오디오 조작을 잠근다.
- 연결 이전에 시작된 상태 조회 응답이 새 동기 세션의 오디오를 정지시키지 않도록 세션을 비교한다.
- AP 진입 시 진행 중인 STA 연결 시도를 중단하고 AP 사용 중 자동 재접속을 억제한다.
  포털의 명시적 Wi-Fi 연결 테스트는 유지한다. AP 채널 영향은 가능한 경로이며 실측 원인으로 단정하지 않는다.
- SyncStart 및 status에 AP/화면/세션/재생/위치/stale 진단 로그를 추가했다.
