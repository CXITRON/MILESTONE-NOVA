기기에 연결하는 중

나의 MILESTONE

기기 MENU에서 모드를 선택하고 OK로 적용합니다. AP를 닫으면 선택한 모드로 돌아갑니다. NOW의 iPhone 연결은 AP 종료 후 시작됩니다.

로컬 미디어

사진·GIF·영상은 이 브라우저에서 변환한 후 SD에 저장합니다. 변환 완료 자료는 브라우저에 남아 업로드 중단 후 재개할 수 있습니다.

AP Sync

영상은 기기의 SD에서 재생하고, 소리는 브라우저에서 재생합니다. 같은 원본 영상을 선택해 변환·전송을 완료한 뒤 시작하세요. 동기 종료 후에는 같은 영상으로 다시 연결할 수 있습니다. 기기에서 BACK으로 AP를 닫거나 모드를 바꾸면 임시 영상을 정리합니다.

NOW / 앨범아트

AMS는 iPhone의 곡 정보와 지원 재생 명령을 제공합니다. 아트는 기존 MILESTONE Artwork 서비스에서 조회합니다. 기기의 OK 조작은 iPhone이 해당 명령을 지원할 때 표시됩니다.

Wi-Fi 연결

2.4 GHz Personal/Open 또는 PEAP를 시험 연결합니다. 성공 상태가 2초 이상 유지된 프로필만 저장됩니다. WPA3 전용 및 서버 CA 검증을 요구하는 Enterprise 구성은 지원 대상에서 제외되어 표시됩니다.

설정 AP

화면과 환경

분류를 펼쳐 값을 바꾸고 항목마다 저장합니다. 환경 임계값은 낮음 < 높음 ≤ 위험 순서로 설정합니다. 검색하면 일치하는 항목이 있는 분류만 펼쳐집니다.

관리와 복구

서명 업데이트

기기는 부팅 후와 하루 한 번 GitHub Releases의 새 정식 버전을 확인해 알려 줍니다. 내려받은 파일은 펌웨어에 내장된 NOVA 공개키로 서명을 검증합니다. 자동 업데이트를 켜면 새 버전을 찾았을 때 기기 버튼 없이 설치 후 재시작하고, 꺼 두면 기기에서 OK를 길게 눌러 설치합니다.
